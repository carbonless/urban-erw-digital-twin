# Urban ERW Digital Twin

Phase 1 demonstrator for visualizing, communicating, and tracking Explosive Remnants of War (ERW) hazards and humanitarian mine-action activities in complex urban environments.

## Overview

A browser-based 3D demonstrator using CesiumJS as the geospatial visualization layer, complementing the existing ArcGIS-based mine-action information-management ecosystem.

## Organization

- **Project**: GICHD Urban Humanitarian Demining and ERW Digital Twin
- **Organization**: VEA Systems
